Executive Overview & Industry Analysis
The 4 Agent Barriers

1. The Autonomous Agent Crisis

AI coding agents (Antigravity IDE, Claude Code, Cursor, Aider, and custom harnesses) have transformed software engineering from manual syntax writing to high-velocity autonomous orchestration. However, in production teams and mission-critical repositories, four structural barriers prevent enterprise confidence:

1. Unpredictable Quadratic Cost Cost Shock

Nobody knows if an agent prompt will cost $3 or $300. As trajectories expand across 30+ turns, repeated full-context inputs cause prompt tokens to accumulate quadratically. Unchecked error-retry loops burn API limits in minutes.

2. Fragmented Provider Governance Siloed Limits

Usage caps live in separate web consoles across OpenAI, Anthropic, OpenRouter, and Ollama. Developers have no unified switchboard to enforce project-level spending caps, daily allowances, or graceful model downgrades.

3. Binary Trust & Repository Regressions No Middle Ground

Engineers are forced into extreme choices: either micromanage and approve every single read-only command, or grant blind autonomous access where a misaligned tool call deletes migrations, wipes configuration, or damages working trees.

4. Desk-Bound Supervision Paralysis Tethered Devs

Agent workflows take 15–45 minutes to implement multi-file tasks. The moment an agent requests confirmation, triggers an IDE dialog, or exhausts an uncalibrated budget, the run stalls completely unless the developer is glued to their monitor.

Module Deep-Dive: Git Shadow Snapshots & Reversible Safety
Safety Layer

9. The Git Shadow Undo Engine

The most disruptive risk of autonomous agents is silent repository corruption. Cairn introduces Git Shadow Snapshots: a sub-20ms checkpoint engine built on low-level Git plumbing that operates completely off-branch without making dummy commits:

Figure 3.1: Cairn Safety Center — Git Shadow snapshot journal, diff preview inspector, and instant rollback trigger.

How Off-Branch Snapshots Work

1. Before executing any mutating action (write_file, edit_file, bash), Cairn executes git write-tree in the background.
2. The raw SHA-1 tree object is written directly to refs/cairn/checkpoints/<run_id>/<step_id>.
3. The user's current branch head (HEAD) and git log remain 100% pristine and unpolluted.

Sub-20ms Atomic Working Restore

When an agent introduces a regression or breaks 40 files:
1. User clicks Revert Step in the IDE or on phone.
2. Cairn executes git read-tree <tree_sha> followed by git checkout-index -a -f.
3. The entire working directory is restored in under 20 milliseconds without merge conflicts.

10. Safety Policy Precedence: Deny > Ask > Allow

Cairn classifies every tool execution through a declarative deterministic policy engine:

ALLOW (Zero Friction)

Read-only queries: read_file, list_dir, grep_search, run_tests. Auto-forwarded instantly with zero latency penalty.

ASK (Gated Approval)

Mutating actions: write_file, edit_file, git_push, npm_install. Stream paused; diff preview broadcast to IDE and phone.

DENY (Hard Blocker)

Known catastrophic patterns: rm -rf /, drop database, git push --force main. Blocked unconditionally with synthetic error.

Mobile Remote

11. Mobile Remote & Three-Layer Control

Developers should not be chained to their desks during 30-minute agent runs. Cairn serves a zero-install, responsive Progressive Web App (PWA) with a three-layer control hierarchy:

Figure 4.1: Cairn Mobile Remote Cockpit — Biometric passkey, live tool approval diffs, and window streaming.
LAYER 1: STREAM GATEWAY

Universal across all agents. Inspect live token burns, streaming thoughts, and tool call diffs. Approve, reject, or inject steering instructions into the active turn.

LAYER 2: IDE RPC BRIDGE

Bi-directional WebSocket bridge to Antigravity IDE, VS Code, and Cursor. Trigger editor commands, accept/reject inline diffs, switch files, and send prompts.

LAYER 3: OS WINDOW BRIDGE

Low-latency WebRTC video stream of target IDE windows (Antigravity.exe, devenv.exe). Translates mobile touch taps and macros directly into native Win32 window inputs.

Hardware-Level Window Privacy & WebAuthn Biometrics

Unlike traditional VNC or remote desktop software that broadcasts your entire desktop, Cairn's OS Window Bridge binds exclusively to the designated IDE process handle (HWND). Your personal browser windows, messaging apps, and local files cannot be seen. High-risk operations require TouchID, FaceID, or hardware passkey verification.
